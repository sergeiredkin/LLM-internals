# TinyStories

- **Dataset:** `roneneldan/TinyStories`
- **Source:** https://huggingface.co/datasets/roneneldan/TinyStories
- **Paper:** https://arxiv.org/abs/2305.07759
- **License:** CDLA-Sharing-1.0
- **Content:** Synthetic short stories generated by GPT-3.5 and GPT-4.

The preparation script downloads the first official training Parquet shard and the official
validation shard. By default it extracts 50,000 training and 5,000 validation documents,
then trains an 8,000-token byte-level BPE tokenizer.

Raw Parquet files, extracted JSONL documents, binary token streams, and tokenizer artifacts
are generated locally and excluded from Git.

```bash
python -m scripts.prepare_tinystories
python -m scripts.inspect_tokenizer
```
